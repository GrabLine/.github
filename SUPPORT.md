## Report a bug

Use the affected repository's bug form when one is available. Desktop and
extension bugs use [GrabLine's issue forms](https://github.com/GrabLine/GrabLine/issues/new/choose).
Website bugs also use those forms, with the `area:website` label.

Include:

- App and extension versions, OS/architecture, and browser/version if relevant.
- Whether you use an installed, portable or source build.
- Exact reproduction steps, expected behaviour and the actual error.
- A short public or synthetic sample when possible.
- A screenshot or sanitized diagnostics/log excerpt, and whether the problem
  occurs in the app alone or only through the browser.

Remove cookies, passwords, keys, token-bearing URLs, private paths and unrelated
history. Do not post personal databases, browser profiles, keyring contents or
raw crash dumps. Settings → About → Copy diagnostics is a useful starting point;
review its contents before sharing.

## Features and contributions

Describe the concrete task a proposed feature would improve, your suggested
behaviour and any workarounds. Read
[Contributing](https://github.com/GrabLine/GrabLine/blob/main/CONTRIBUTING.md)
before making a substantial change. The desktop app and GrabLine Connect are
maintained together in one repository.

## Security reports

Report exploitable vulnerabilities privately through the affected repository's
Security → Report a vulnerability form. See [SECURITY.md](SECURITY.md).
Do not disclose an exploit in a public issue. There is no guaranteed support
or security-response deadline.
